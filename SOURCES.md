# Sources and asset documentation

## Competition requirements

- Future Business Leaders of America. *2026-2027 Competitive Events Guidelines: Website Coding & Development*. Updated August 2026. Supplied by the project team as `Website-Coding-and-Development.pdf`.

The competition document informed the project's focus on accessibility, responsiveness, functional interactivity, original source code, consistent design, and clear documentation.

## Visual assets

- CivicShift logo mark: original inline SVG created for this project.
- Dashboard, calendar, opportunity art, icons, and decorative graphics: original HTML/CSS/SVG created for this project.
- Minimal quest-board paper surfaces, folded corners, and cause stamps: original CSS and inline SVG created for this project. Personal quest marks use original styling and standard text symbols.
- No stock photography, external icon library, website template, or third-party visual asset is used in the current website or demonstration portal.

## Typography

- Manrope is loaded from Google Fonts for body text and interface controls, with system sans-serif fallbacks.
- Georgia is used for the minimal interface's editorial and quest headings, with Times New Roman and generic serif fallbacks. These are system fonts; no additional serif font file is downloaded or bundled.

## Demo content

All names, organizations, schools, opportunities, dates, contact details, capacity figures, hours, messages, and dashboard metrics shown across the website are fictional demonstration content. They are not claims about real organizations or people.

Original legacy occupancy counts are labeled fictional in the demo and preserved during migration.

## Gamified service release

The team-approved CivicShift gamified app plan defines the original scoring policy, personal quests, opt-in school cooperation, and attendance-code demonstration. Points are a transparent participation/reliability record, not a validated measure of personal worth or service quality. No third-party game assets, news text, or proprietary scoring algorithm are used.

Competitive references discussed during planning include [POINT](https://pointapp.org/nonprofit-features/), [GivePulse](https://learn.givepulse.com/service-learning), and [Idealist](https://www.idealist.org/en/volunteer). These informed comparisons with existing discovery and verification workflows; CivicShift does not integrate their services or claim affiliation.

All new quest icons, badges, game layouts and fictional examples are original HTML/CSS/text. Codex assisted with implementation, testing and documentation; the student team should review and adapt the work and follow its competition disclosure rules.
