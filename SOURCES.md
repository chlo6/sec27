# Sources and asset documentation

## Competition requirements

- Future Business Leaders of America. *2026-2027 Competitive Events Guidelines: Website Coding & Development*. Updated August 2026. Supplied by the project team as `Website-Coding-and-Development.pdf`.

The competition document informed the project's focus on accessibility, responsiveness, functional interactivity, original source code, consistent design, and clear documentation.

## Visual assets

- CivicShift logo mark: original inline SVG created for this project.
- Dashboard, calendar, opportunity art, icons, and decorative graphics: original HTML/CSS/SVG created for this project.
- No stock photography, external icon library, website template, or third-party visual asset is used in the current website or demonstration portal.

## Typography

- Manrope is loaded from Google Fonts and used as the primary interface typeface, with system sans-serif fallbacks.

## Demo content

All names, organizations, schools, opportunities, dates, contact details, capacity figures, hours, messages, and dashboard metrics shown across the website are fictional demonstration content. They are not claims about real organizations or people.

## Prototype references and assistance

- [Team planning document](https://docs.google.com/document/d/1WR6gRR0LEPFKyYhEFSWK0P2czO4A8c63o22VufwZEF0/edit?tab=t.l2apvw8aek8s): Volunteer Management ideas and the implementation plan approved by the team.

- The team's Muse-inspired concept informed a visible assistant with suggested actions, explanations, and explicit confirmation. This prototype does not import Meta software, claim feature parity, or use a live model. Recommendations and tool actions are deterministic JavaScript.
- Codex assisted with prototype implementation, tests, documentation, and original CSS artwork. Team review and authorship/assistance disclosures remain the team's responsibility.

New story illustrations are abstract CSS compositions and text symbols. No remote image service, stock photo, or external script is required. Google Fonts serves Manrope; system fonts provide the fallback if it is unavailable. Original legacy occupancy counts are labeled fictional in the demo and preserved during migration.
